## 1. 玩法與核心循環

### 1.1 一句話核心循環

**選模式 → 選英雄 → 一鍵配對 → 2.5~3 分鐘短局 → 結算揭曉獎盃/星球員 → 領獎勵（獎盃推進榮耀之路、代幣升級英雄、星落禮盒開箱）→ 立刻想再來一場。** 整個循環壓在 **3~5 分鐘**，讓「再一場」成本極低——這是 Supercell 手遊留存的引擎。

### 1.2 模式一覽

| 模式 | 隊伍 | 勝利目標 | 每場時間 | 專屬機制 |
|---|---|---|---|---|
| 寶石爭奪戰 Gem Grab | 3v3 | 隊伍先集滿 **10 顆寶石並撐住 15 秒**倒數 | ~2.5 分 | 地圖中央寶石礦定時吐寶石；死亡會掉光寶石；「撐倒數」製造逆轉張力 |
| 荒野生死鬥 Showdown | 單人/雙人（大逃殺 10~12 人） | 活到最後 | ~2.5 分 | 地圖持續縮小（毒霧）；打破箱子撿能量塊變強（攻/血↑）；後期強者滾雪球 |
| 亂鬥足球 Brawl Ball | 3v3（另有 5v5） | 先進 **2 球**，或 2 分鐘後比分領先 | 2 分（+1 分加時） | 帶球被擊倒球會掉；踢球/搶球節奏；平手進加時黃金球 |
| 據點爭奪 Hot Zone | 3v3 | 佔領區域累積佔領值 | ~2.5 分 | 站在圈內累積進度，逼玩家「站定點對峙」 |
| 金庫攻防 Heist | 3v3 | 炸毀對方保險庫 / 比對方保險庫血量低 | ~2.5 分 | 有明確攻防目標物（我們的「神木」可對應） |
| 賞金獵人 Bounty | 3v3 | 擊殺累積星星，時間到星星多者勝 | ~2.5 分 | 連殺提高自己身價（被殺給對方更多星）＝風險/報酬 |
| 活動/週末模式 | 變動 | 變動 | — | 機甲亂鬥、超級城市等輪替，維持新鮮感 |
| 排位賽 Ranked | 3v3 | 三戰兩勝（高階）；Ban/Pick | 多局 | 競技向；牌位 Bronze→Pro |

**設計要點**：模式全部共用同一套操作與英雄，**只換「勝利目標與地圖規則」**。玩家不必重學操作，卻能感覺玩到完全不同的遊戲——極高的內容複用率。

> 交給 art agent 深入：每個模式有專屬的**目標物視覺**（寶石礦、球門、保險庫、佔領圈），且地圖有**牆/草叢**兩種戰術地形（草叢＝隱身伏擊）。我們可對應到「棲地地形」原創設計。

### 1.3 對局內每場結構

1. **開局**：3-2-1 倒數（我們已有）。
2. **對峙期**：靠牆/草叢走位，用普攻蠶食、集氣。
3. **交火期**：超級技能充滿後開團，決定性交鋒。
4. **收尾期**：目標達成倒數（如寶石爭奪「10 顆撐 15 秒」）製造最後張力與逆轉窗口。

### 1.4 對局內「變強」層（Progression 在戰鬥中的即時體現）

| 層 | 觸發 | 效果 | 對應我們現況 |
|---|---|---|---|
| 彈藥/裝填 Ammo | 普攻消耗彈藥格、自動回填 | 逼玩家控節奏、別空放 | 我們用 `cd` 攻擊間隔，可視覺化成彈藥格 |
| 超級技能充能 Super | **造成傷害**（部分角色受傷也充）填滿大招條 | 集氣式大招 | 我們是「撿拾式必殺（守護之力 relic）」——不同路線，各有優點 |
| 配件 Gadget | 每場有限次數的即時道具（冷卻/次數制） | 戰術變化 | 我們天賦第 3 級 `active.effect`，但**沒有戰場內按鈕觸發的有限次道具** ← 缺口 |
| 星徵 Star Power | 被動特性（局內恆常生效） | 角色個性化 | 我們天賦樹被動加成（`dmg/speed/spCd/dr`）已對應 |
| 極限充能 Hypercharge | 約 3 個大招的傷害量再充滿；按鈕啟動 | 短時間全面強化（+傷/+盾/+速） | 我們**無**「終極的終極」層 ← 可作為首領戰高潮 |

### 1.5 局外 Progression（長線成長）

| 系統 | 貨幣/資源 | 作用 | 我們對應 |
|---|---|---|---|
| 獎盃 Trophies | 勝負增減 | 每隻英雄各自累積；總獎盃推進榮耀之路 | 我們有 XP/等級、首領難度晉級，但**無「勝負增減、會掉的天梯分」** |
| 榮耀之路 Trophy Road | 總獎盃里程碑 | 過門檻解鎖新英雄/資源/星落禮盒 | **強對應** → 累積保育值里程碑解鎖守護者（已有雛形，可強化成「路線圖 UI」） |
| 牌位/排位 Ranked | Elo | Bronze/Silver/Gold/Diamond/Mythic/Legendary/Masters/Pro（每階 3 級，共 22 階）；賽季重置 | 我們首領挑戰「見習→大師」5 級是簡化版，可再視覺化 |
| 星妙之路 Starr Road | 積分/Credits | 主動選擇解鎖想要的英雄 | 對應保育值解鎖，但我們是「單向解鎖」非「路線選擇」 |
| 精通 Mastery | 用某英雄持續遊玩 | 專精獎勵（代幣/資源） | **缺口**：我們沒有「常玩某隻守護者的專精獎勵」 |
| 星落禮盒 Starr Drops | 每日勝利/連勝掉落 | **開箱式隨機獎勵**（稀有度 Rare→Legendary，2s/4s/6s/8s 蓄力揭曉） | **缺口**：我們有每日任務→通行證，但**無開箱揭曉的期待感** |
| 通行證 Brawl Pass | 賽季進度 | 免費+付費雙軌逐格領獎 | 我們有通行證點數換服裝，是簡化版 |

**星落禮盒稀有度掉率**（官方）：Rare 50% / Super Rare 28% / Epic 15% / Mythic 5% / Legendary 2%。**揭曉時「握住越久獎勵越好」的 2/4/6/8 秒蓄力** 是它最強的期待感設計。

## 2. 流程與場景／過場（step-by-step）

> 這是本報告重點。每一步描述：**畫面內容 / UI 元素 / 轉場動畫 / 給玩家的回饋**。標「（推斷）」者為合理重建。我們的實作全部走 Canvas 純繪製、單檔零外部資源（見鐵則）。

### Step 0 — 開 App / 讀取（Loading）
- **畫面**：品牌 logo → 讀取條，**讀取畫面顯示一句遊戲小知識/提示**（新手教學、角色梗）。
- **回饋**：讀取時間被「小知識」填滿，玩家不覺得在等。
- **交給我們**：讀取畫面塞**台灣生態冷知識**（「石虎全台不到 500 隻」），一舉兼顧宗旨＋消除等待感。

### Step 1 — 大廳 / 主畫面（Lobby）
- **畫面佈局**：
  - **正中央**：你目前選的英雄，**大、立體、待機小動作**（呼吸/晃動/偶爾撥毛）。點角色 → 進更換英雄。
  - **角色旁 `+` 號**：邀請好友/戰隊組隊。
  - **右下角巨大黃色「對戰」鈕**：全畫面最搶眼的 CTA；鈕上方顯示代幣存量。
  - **上方/側邊**：模式選擇入口、獎盃數、貨幣、賽季通行證進度、每日任務。
- **轉場/juice**：大廳背景輕微視差、英雄待機動畫、按鈕 hover/按下有彈性縮放與音效；有可領獎勵時**徽章跳紅點/彈跳**吸引點擊。
- **給玩家回饋**：一眼知道「我要做什麼」（按黃鈕）＋「我有什麼新東西可領」（紅點）。
- **我們現況**：已有「更換守護者」彈窗、服裝店、通行證、每日任務、3-2-1。**待補**：中央守護者的**待機小動作**、對戰鈕的**視覺主導性**、可領獎勵的**紅點/彈跳提示**。

### Step 2 — 模式選擇（Mode Select）
- **畫面**：模式卡片列表（每個模式一張卡：圖示 + 名稱 + 當前地圖縮圖 + 目標一句話）。
- **轉場**：卡片橫向滑動切換，選中卡放大高亮。
- **回饋**：每張卡直接畫出「這模式在幹嘛」，降低理解門檻。
- **我們現況**：已有一般/限時/PVE/首領四模式選單。**待補**：模式卡的**視覺化目標一句話 + 地圖縮圖**，讓新手秒懂差異。

### Step 3 — 更換英雄（Brawler Select）
- **畫面**：英雄網格；每個頭像顯示等級/稀有度/是否已解鎖（鎖頭）；選中的英雄在旁邊大圖展示招式與星徵/配件。
- **轉場**：點頭像 → 大圖區滑入該英雄，播一個小的「登場 pose」。
- **回饋**：解鎖進度可見（誘因）、已裝備的星徵/配件一目了然。
- **我們現況**：已有選角網格 + 服裝。**待補**：選中時的**登場 pose 過場**、鎖定角色顯示**「還差多少保育值解鎖」的進度條**（把 Trophy Road 的誘因搬進來）。

### Step 4 — 組隊 / 配對（Party / Matchmaking）
- **單人**：直接按「對戰」→ 系統快速配對（配對盡量避開高手輾壓新手）。
- **組隊**：`+` 邀好友，湊 2~3 人共一隊。
- **轉場**：按對戰 → **配對轉圈/尋找對手動畫** → 湊齊玩家頭像逐一「啪」地落位。
- **回饋**：找對手時有進度感（頭像一個個亮起），不是乾等。
- **我們現況**：好友房間（N 人、選角+ready）已完整，但**無「單人快速配對」的隨機/NPC 對手流程**（大廳「對戰」偏向房間）。**待補**：單人一鍵配對（可先用 NPC 假配對動畫，符合沙盒測不到 Firebase 的限制）。

### Step 5 — 開場（Match Intro）
- **畫面**：讀取進戰場 → **雙方隊伍亮相**（英雄名 + 頭像滑入）→ **3-2-1-GO** 大字倒數 → 開打。
- **轉場/juice**：進場鏡頭拉近戰場、隊伍名字有力地滑入、GO 字爆開、開打瞬間音效重擊。
- **回饋**：明確的「準備—開始」儀式感，腎上腺素拉起。
- **我們現況**：已有 3-2-1 倒數、首領登場電影運鏡（letterbox+名號+紅色掃光+威壓音效——這其實已達 Supercell 水準）。**待補**：把首領登場那套「電影運鏡」**降規版**用到一般對局開場（雙方隊伍亮相），讓每場都有儀式感。

### Step 6 — 對局中（In-Battle HUD）
- **畫面 HUD**：
  - **左下**：虛擬搖桿（移動+走位）。
  - **右下**：普攻搖桿——**點=自動瞄準最近敵人**、**拖曳=手動預判方向/距離並顯示瞄準線**。
  - **超級技能鈕**：充能滿了才亮/可按；旁邊常有**配件鈕**（有限次數/冷卻）。
  - **彈藥格**：普攻消耗、自動回填的視覺格。
  - 頭頂血條、目標進度（寶石數/比分/佔領%）、隊友位置。
- **juice**：命中有**傷害浮字 + 命中火花 + 螢幕微震 + 手機震動**；血條**平滑減少**（不瞬間跳）；大招/擊殺有較大震動與定格感。
- **回饋**：每個輸入都有立即、誇張但清楚的回應——這是「手感」的核心。
- **我們現況**：**已非常接近**——Pointer 搖桿、屬性相剋、hit-stop、命中火花、傷害浮字、螢幕震動、必殺都有。**待補**：①瞄準線（拖曳預判可視化）②彈藥格視覺 ③戰場內「有限次配件鈕」④血條平滑過渡（若目前是瞬跳）。

### Step 7 — 結算（Result）
- **畫面**：**勝利 / 失敗大字橫幅**（勝利金光、失敗灰暗）→ **記分板**（雙方玩家、傷害/擊殺/目標貢獻）→ **★星球員（Star Player）** 高亮一名 MVP（依傷害+目標貢獻選出）。
- **轉場/juice**：勝利有金色粒子噴發、勝利號角；星球員頭像放大加冠冕/星光。
- **回饋**：即使輸了也能看到自己的貢獻（星球員可跨隊選？實際只在勝隊/表現最好者），給「下次會更好」的動力。
- **我們現況**：有 `showOver` 結算 + combo 顯示。**待補**：**星球員（本場 MVP）**機制與高亮動畫、**記分板貢獻數據**（傷害/擊殺/驅逐入侵種數）。

### Step 8 — 獎勵揭曉（Reward Reveal）
- **畫面**：結算後**逐項揭曉**：獎盃 +/-（榮耀之路進度條動起來、經過里程碑時「叮」地解鎖）、經驗/代幣飛入、**星落禮盒開箱**。
- **轉場/juice（最強的期待感設計）**：
  - 獎盃數字**逐格跳動累加**、進度條**充能動畫**，快到里程碑時放慢製造懸念。
  - **星落禮盒**：一顆發光禮盒，**握住蓄力（2/4/6/8 秒），越久稀有度越高**，放開時**爆開揭曉**內容（稀有度用顏色/光效/音效區分，Legendary 全螢幕金光）。
  - 每一項獎勵**一件一件飛入/彈跳到對應欄位**，配「叮/噹」音效。
- **回饋**：把「領獎勵」變成一段有節奏、有懸念、有爽點的**小演出**，這是留存與「再來一場」的關鍵鉤子。
- **我們現況**：有票券飛入徽章的小動畫、每日任務。**待補（高價值）**：①獎盃/保育值**逐格跳動 + 進度條充能到里程碑解鎖**的揭曉演出 ②**開箱式獎勵**（我們原創：「復育補給箱」蓄力揭曉，內容是服裝/保育值/守護者碎片，稀有度用台灣生態配色）。

### Step 9 — 回大廳 / 再一場（Loop Back）
- **畫面**：回大廳，或直接「再來一場（同模式同英雄）」快速鈕。
- **回饋**：一鍵重開，摩擦最小化。
- **我們現況**：已有「再守一場/下一關」「↩ 回到小隊」。**佳**，維持即可。

### 流程總覽圖

```
開App→讀取(生態小知識)
  └→ 大廳(中央守護者待機動畫 / 巨大對戰鈕 / 紅點提示)
       ├→ 模式選擇(卡片:圖示+目標一句話+地圖縮圖)
       ├→ 更換守護者(網格+登場pose+解鎖進度條)
       └→ 對戰鈕
            └→ 配對(頭像逐一落位動畫 / 單人可NPC假配對)
                 └→ 開場(雙方隊伍亮相 + 3-2-1-GO 儀式)
                      └→ 對局(搖桿+瞄準線+彈藥格+超級技能+配件鈕 / 全程juice回饋)
                           └→ 結算(勝敗大字 + 記分板 + ★星球員MVP)
                                └→ 獎勵揭曉(保育值逐格跳+里程碑解鎖 + 開箱蓄力揭曉)
                                     └→ 回大廳 / 一鍵再一場
```

## 3. 他們為什麼好玩（設計原則）

1. **即時、誇張、清楚的回饋（juice）**：每個輸入都立刻有視覺+聽覺+觸覺回應（傷害浮字、火花、震動、血條平滑減少）。玩家「感覺得到」自己在打中人。
2. **低門檻、高天花板**：操作只有「移動/攻擊/大招」三件事，10 秒學會；但走位、預判、集氣時機、地形利用、英雄剋制、星徵配件搭配讓深度無上限。
3. **短局、快節奏、低再玩摩擦**：2.5~3 分鐘一局 + 一鍵再來，「再一場」成本趨近於零 → 高留存。
4. **獎勵揭曉的期待感**：把「領獎」設計成一段有懸念的小演出（逐格跳動、里程碑解鎖、開箱蓄力揭曉），而非一次把數字塞給你。**期待 > 獲得本身**。
5. **社交/組隊鉤子**：`+` 一鍵邀好友組隊、共享勝利、戰隊歸屬感；配對系統保護新手不被輾壓，維持正回饋。
6. **內容高複用**：同一套操作與英雄，靠「換勝利目標＋換地圖規則」變出十幾個模式，開發效率與玩家新鮮感兼得。
7. **多條互不干擾的成長軸**：獎盃（技術天梯）／等級（時間投入）／星妙之路（選擇）／通行證（賽季）／精通（專精）並行，總有一條在推進，玩家永遠「差一點就升級」。

## 4. ★對應到守土的可行改進（需求單）

> 依 `docs/PROCESS.md §3` 模板開單，編號 `R-BS-01…`。**只借原則與手感，主題/美術/species 全用台灣生態原創、不抄襲。**
> 難度：S(小,<半天) / M(中,1~2天) / L(大,需設計定案)。鐵則檢核：單檔零外部資源、Canvas 純繪製、資料合約不改壞、粒子上限+回收。

### R-BS-01 獎勵揭曉演出（保育值逐格跳 + 里程碑解鎖）
- **使用者原話**（推導自研究）：結算後的獎勵要有「一格一格跳、快到里程碑放慢」的期待感，不要一次塞數字。
- **意圖釐清**：結算後保育值/XP **數字逐格累加動畫**，畫一條「保育之路」進度條，**跨過解鎖守護者/服裝的里程碑時放慢+閃光+音效+彈出「已解鎖」**。借 Trophy Road/獎勵揭曉節奏，主題原創（保育里程碑）。
- **對應系統**：大廳/UI | 對戰（結算 `showOver`）
- **驗收條件**：
  - [ ] 結算保育值/XP 逐格跳動（可跳過）
  - [ ] 保育之路進度條動畫，經里程碑時解鎖演出
  - [ ] 純 Canvas 繪製、粒子有上限+回收、`node --check` 過、無頭 0 error
- **預估難度**：M
- **鐵則影響**：無違反（純繪製；沿用 `__getEco/__conservationLevel`，不改鍵名）
- **狀態**：待辦

### R-BS-02 復育補給箱（開箱式蓄力揭曉，原創版 Starr Drop）
- **使用者原話**（推導）：想要「開箱」那種握住越久、越好、爆開揭曉的爽感。
- **意圖釐清**：每日勝利/連勝掉一顆「復育補給箱」，玩家**按住蓄力（2/4/6/8 秒，越久稀有度越高）**放開爆開揭曉；內容為**保育值/服裝/守護者解鎖碎片**，稀有度用**台灣生態配色**（普通→稀有→史詩→傳說＝綠→藍→紫→金）。掉率原創、不照抄。
- **對應系統**：大廳/UI | 通行證/成長
- **驗收條件**：
  - [ ] 蓄力揭曉互動（Pointer 長按，`{passive:false}`+`preventDefault`）
  - [ ] 稀有度加權隨機 + 對應光效/音效（`__sfx`）
  - [ ] 獎勵發放走既有中樞（`__awardEco`/服裝/解鎖），新增 `shoutu_supply_*` 鍵（不改既有鍵語意）
  - [ ] 粒子上限+回收、單檔零外部資源、無頭 0 error
- **預估難度**：L（需先定掉率表與獎池品項——**建議問使用者 1 個問題：補給箱獎池要放哪些品項？**）
- **鐵則影響**：無違反（純繪製、純 Web Audio）
- **狀態**：擱置（等獎池定案）

### R-BS-03 星球員（本場 MVP）+ 記分板貢獻數據
- **使用者原話**（推導）：結算要選一個 MVP 高亮，並顯示每人貢獻。
- **意圖釐清**：結算記分板顯示各守護者**傷害/擊退入侵種數/目標貢獻**，依綜合分選出**「本場守護之星」**高亮（冠冕/星光/放大）。輸也顯示貢獻給正回饋。
- **對應系統**：對戰（結算）| 大廳/UI
- **驗收條件**：
  - [ ] 對局中統計各角色傷害/擊殺（不新增網路欄位或最小化——可只在 host 端算）
  - [ ] 結算記分板 + MVP 高亮動畫（純繪製）
  - [ ] 連線快照不塞非必要欄位（維持 §B.5 最小欄位原則），或僅結束時單次同步
  - [ ] 無頭 0 error
- **預估難度**：M
- **鐵則影響**：注意 netcode 快照最小化原則（`docs/SYSTEMS.md §B.5`）——貢獻統計盡量本地/結束時算，別每幀塞快照
- **狀態**：待辦

### R-BS-04 對局內瞄準線 + 彈藥格 HUD
- **使用者原話**（推導）：攻擊時要能看到瞄準方向/距離，普攻要有彈藥節奏感。
- **意圖釐清**：右下攻擊搖桿**拖曳時畫預判瞄準線**（方向+射程虛線/扇形）；普攻改成**彈藥格**視覺（消耗+自動回填），逼玩家控節奏。借 Brawl Stars HUD，數值用我們既有 `cd`。
- **對應系統**：對戰 | 美術/打擊感
- **驗收條件**：
  - [ ] 拖曳攻擊顯示瞄準線（放開才出手，維持既有 Pointer 合約，不改 dock 按鈕 id）
  - [ ] 彈藥格 UI 對應攻擊間隔
  - [ ] 觸控 `touch-action:none`、安全區不動（鐵則）
  - [ ] 無頭 0 error、粒子上限
- **預估難度**：M
- **鐵則影響**：**不可改** `bLeft/bRight/bSwap/bJump/bSp/bAtk` id 與 Pointer 輸入合約——只加視覺層
- **狀態**：待辦

### R-BS-05 戰場配件鈕（有限次即時道具）
- **使用者原話**（推導）：想要局內有「有限次數的戰術道具」按鈕，不只被動天賦。
- **意圖釐清**：每隻守護者一個**專屬「守護配件」**（每場有限次/冷卻，如石虎「草叢突襲」瞬移、黑熊「震地」擊退），戰場多一顆配件鈕。原創技能，非抄 Gadget 具體效果。
- **對應系統**：對戰
- **驗收條件**：
  - [ ] 每隻一個配件、次數/冷卻 UI、Pointer 觸發
  - [ ] 連線同步（配件觸發需進 input 或事件，注意 host-authoritative）
  - [ ] 純繪製特效、粒子上限、無頭 0 error
- **預估難度**：L（需為 13 隻各設計 1 個配件 → 建議分批）
- **鐵則影響**：可能新增 input 欄位——需同步 `net.js` inputs schema，勿改既有欄位語意
- **狀態**：待辦

### R-BS-06 大廳升級：中央守護者待機動畫 + 對戰鈕主導 + 可領紅點
- **使用者原話**（推導）：大廳要更「活」、對戰鈕更搶眼、有東西可領要提示。
- **意圖釐清**：中央守護者加**待機小動作**（呼吸/偶爾動作，用既有 `drawCreature` 的 `t/ph` 相位，不改簽名）；**放大主「對戰」鈕**的視覺權重；有每日任務/補給箱/新解鎖時**徽章跳紅點/彈跳**。
- **對應系統**：大廳/UI | 美術/打擊感
- **驗收條件**：
  - [ ] 待機動畫僅用 `drawCreature(c,kind,x,y,s,o)` 既有 `o` 欄位（`t/mood/ph`），**簽名不改**（鐵則）
  - [ ] 對戰鈕視覺主導、hover/按下彈性
  - [ ] 可領項目紅點提示（讀既有任務/通行證狀態）
  - [ ] 無頭 0 error
- **預估難度**：S~M
- **鐵則影響**：**嚴守 `drawCreature` 簽名與 8 kind 支援**
- **狀態**：待辦

### R-BS-07 模式選擇卡片化（圖示 + 目標一句話 + 縮圖）
- **使用者原話**（推導）：模式選單要一眼看懂差異。
- **意圖釐清**：四模式改**卡片式**，每卡：圖示 + 名稱 + **目標一句話**（「守好苗圃、驅逐入侵種」）+ 小地圖縮圖 + 目前進度（PVE 關卡/首領難度）。降低新手理解門檻。
- **對應系統**：大廳/UI
- **驗收條件**：
  - [ ] 四模式卡片、選中放大高亮、Pointer 切換
  - [ ] 顯示各模式進度（沿用 `shoutu_pve_level`/`shoutu_duel_level`）
  - [ ] 純繪製、無頭 0 error
- **預估難度**：S
- **鐵則影響**：無
- **狀態**：待辦

### R-BS-08 一般對局開場儀式（雙方隊伍亮相，首領運鏡降規版）
- **使用者原話**（推導）：每場開場都要有儀式感，不只首領戰有。
- **意圖釐清**：把首領登場那套電影運鏡做**降規版**用到一般/PVE 開場：**雙方隊伍名字+頭像滑入 → 3-2-1-GO**。復用既有 `BOSS_INTRO` 資產思路。
- **對應系統**：對戰 | 美術/打擊感
- **驗收條件**：
  - [ ] 一般/PVE 開場隊伍亮相動畫（可設定跳過）
  - [ ] 連線與單機一致（走既有 3-2-1 流程，不破壞 net 倒數）
  - [ ] 無頭 0 error、狀態機切換不破壞（鐵則）
- **預估難度**：M
- **鐵則影響**：不可破壞 `title/map/play/post/result` 狀態機流程
- **狀態**：待辦

### R-BS-09 單人快速配對（NPC 假配對動畫）
- **使用者原話**（推導）：單人也要能一鍵「快速配對」開打，有找對手的動畫。
- **意圖釐清**：大廳「對戰」單人路徑 → **配對轉圈 + 頭像逐一落位**（隊友/對手用 NPC，符合沙盒測不到 Firebase 限制）→ 開打。降低單人玩家開一場的摩擦。
- **對應系統**：大廳/UI | 對戰
- **驗收條件**：
  - [ ] 單人一鍵配對動畫（NPC 填位）
  - [ ] 不影響好友房間既有流程
  - [ ] 無頭 0 error
- **預估難度**：M
- **鐵則影響**：無（純本地，不動 net 房間邏輯）
- **狀態**：待辦

### R-BS-10 守護者精通（Mastery：常玩某隻的專精獎勵）
- **使用者原話**（推導）：常玩某隻守護者要有專屬長線獎勵。
- **意圖釐清**：每隻守護者一條**精通進度**（用該隻出戰累積），過門檻給保育值/服裝/專屬圖鑑知識。借 Mastery，主題原創（愈了解該物種、圖鑑知識愈解鎖，扣宗旨）。
- **對應系統**：等級/成長 | 大廳/UI
- **驗收條件**：
  - [ ] 每隻精通進度（新增 `shoutu_mastery` JSON，不改既有鍵）
  - [ ] 里程碑獎勵走既有中樞發放
  - [ ] 精通獎勵含「解鎖該物種真實生態知識」（呼應宗旨）
  - [ ] 無頭 0 error
- **預估難度**：M
- **鐵則影響**：無（新增鍵；沿用 `__awardEco` 等）
- **狀態**：待辦

## 5. 給 art agent 的接手備忘（本報告觀察到的美術點）

- **目標物視覺**：各模式需專屬目標物（我們的神木/苗圃已有，可再設計「復育點/佔領圈」原創版）。→ 交給 art agent 深入。
- **稀有度配色系統**：補給箱/解鎖用一套稀有度色階（建議台灣生態配色：森綠/溪藍/山紫/曙金）。→ 交給 art agent 定調。
- **獎勵揭曉粒子**：逐格跳、里程碑閃光、開箱爆開——需純 Canvas 粒子且**硬上限+回收**（鐵則）。→ 交給 art agent 設計特效預算。
- **星球員高亮**：冠冕/星光的原創版（避免抄 Supercell 皇冠，可用台灣意象如桂冠/羽冠）。→ 交給 art agent。
- **中央守護者待機動畫**：只能用既有 `drawCreature` 的 `o.t/o.ph` 相位驅動，不改簽名。→ 交給 art agent 設計動作幅度。
