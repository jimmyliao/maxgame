# 攻守對決模式（Siege Mode）設計

> 新對戰模式。第一版對手為 AI（未來可擴充真人連線）。本文件是實作前的共識，動工前對齊用。

## 一句話
可選 1v1~5v5 的隊伍規模，分「攻方 / 守方」，三戰兩勝、攻守互換；用錢買「情報道具」互相試探對方位置。

## 1. 隊伍規模
- 開戰前可選：**1v1 / 2v2 / 3v3 / 4v4 / 5v5**。
- 兩隊人數對等。玩家操控其中一隻，同隊其餘由 AI 補位；敵隊全由 AI 操控（第一版）。

## 2. 陣營：攻方 / 守方
- 開戰前玩家選要當**攻方**還是**守方**。
- 每回合場上有一座屬於「守方」的**神木**：
  - **攻方**目標：在時限內攻破守方神木。
  - **守方**目標：撐到時限結束、神木不倒。
- 這直接沿用現有 MOBA 的神木機制，不另造引擎。

## 3. 戰場迷霧 + 情報道具（核心玩法）
- **預設有戰場迷霧**：平常只看得到自己附近的敵人，遠方敵人位置未知。
- 雙方在回合中會累積**金錢**（每秒 + 擊殺獎勵，沿用戰場商店 battleshop 的金幣概念）。
- 用錢開商店買**情報 / 試探類道具**：
  - 守方買道具「試探攻方」＝短暫揭露攻方位置 / 動向。
  - 攻方一樣要用錢買道具才能知道守方位置。
- 「用錢買情報」才有意義的前提就是有迷霧——這是本模式跟現有模式最大的不同。

### 道具（品項待玩家決定，先放佔位）
> 玩家表示「道具還沒想好、我先想好再告訴你」。先用佔位道具讓模式可玩可測，等玩家定案再替換 / 擴充。
- 佔位範例（暫定，之後改）：
  - 🛰️ **偵察雷達**：短暫（~5 秒）揭露全場敵方位置。
  - 💨 **煙霧彈**：短暫（~5 秒）隱藏自己不被對方偵察揭露。
  - （其餘功能鍵等玩家想好再加）

## 4. 回合制：三戰兩勝 + 攻守互換
- 總共最多打 **3 回合**，**先贏 2 回合**者取得整場勝利。
- **每回合結束後攻守互換**（玩家這回合當攻方，下回合當守方）。
- 單回合勝負：
  - 攻方在時限內打爆守方神木 → 攻方勝該回合。
  - 時限到、神木還在 → 守方勝該回合。
- **平手判定**：若三回合打完仍分不出勝負（含和局回合），比較「**累計對敵方神木造成的傷害百分比**」，高者獲勝。

## 5. UI / HUD
- 開戰前 pick 畫面新增「⚔️ 攻守對決」模式，選 1~5 人、選攻/守。
- 對戰上方新增**回合計分板**（例：`第 2 回合　你 1 : 0 敵`）＋角色目前是攻還守的標示。
- 沿用戰場上方金幣 HUD；商店按鈕改用本模式的情報道具清單。

## 6. 技術落點（不破壞鐵則）
- 沿用 `src/moba.js` 引擎：神木 / 小兵 / AI / 命中判定既有邏輯。
- 新增 `pickMode==="siege"` 分支 + 回合狀態機（round、score、side、swap、cumulative shrine dmg）。
- 迷霧與情報道具建議做成可獨立討論的模組 / 區塊，方便之後替換道具。
- 不改 `drawCreatureTop` 簽名與圖檔優先；粒子仍有上限；單檔零外部資源；改檔同步 bump `sw.js`。
